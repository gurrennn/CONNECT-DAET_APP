# 🚀 Quick Start: Enhanced Analytics Dashboard

## ⚡ Get Started in 5 Minutes

### Step 1: Start the Development Server
```bash
npm run dev
```

### Step 2: Open Analytics Dashboard
Navigate to: **http://localhost:3000/analytics**

### Step 3: Sign In
Use the admin account configured in your system.

## 💡 Pro Tips

### Tip 1: Save Time with Presets
Use date range presets instead of custom dates:
- "Last 7 Days" for weekly reviews
- "Last 30 Days" for monthly reports
- "Last 90 Days" for quarterly analysis

### Tip 2: Use Comparison Mode
Always enable "Compare to previous period" to see trends:
- ✅ Revenue up 15.3% (green = good)
- ⚠️ Visitors down 5.2% (red = attention needed)

### Tip 3: Export Early
Export data at the start of your analysis:
- Backup in case of connection issues
- Share with offline team members
- Archive for historical comparison

### Tip 4: Read Insights First
Before diving into charts, read AI insights:
- Highlights key findings
- Flags urgent issues
- Suggests actions

### Tip 5: Check Anomalies Daily
Quick daily check of anomalies:
- Takes 30 seconds
- Catches issues early
- Prevents problems

## 🐛 Common Issues & Fixes

### Issue: Data Not Loading
**Fix:**
1. Check internet connection
2. Click "Refresh Data" button
3. Sign out and sign back in
4. Clear browser cache

### Issue: Export Not Working
**Fix:**
1. Check popup blocker
2. Allow downloads from site
3. Try different format
4. Check disk space

### Issue: Insights Not Showing
**Fix:**
1. Wait for data to load
2. Check date range has data
3. Refresh the page
4. Clear filters

### Issue: Print View Looks Wrong
**Fix:**
1. Use Chrome or Edge
2. Set to "Portrait" orientation
3. Enable "Background graphics"
4. Adjust margins if needed
